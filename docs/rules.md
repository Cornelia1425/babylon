# 游戏规则（Claude 写，2026-11-22）

这份规则对应 这个仓库首页现在能玩的版本（v2）。每条规则后面写了为什么这样定。数值都能改，位置在文末。最终决定权在 Yiran。

## 一句话
两个人各走一条螺旋楼梯，登上一座中空的塔。谁也不用等谁，但只有两个人同时到位，断桥才会合拢，并永远留在塔里。

## 规则

**1. 各走各的路。**
塔的内壁上有两条螺旋楼梯，起点在塔底相对的两侧，一人一条。楼梯是完整的，一个人可以独自走到顶。
*为什么：* 合作不该是门槛。一个人随时能玩，第二个人随时能加入，谁离开都不会卡住另一个。

**2. 气息。**
每个人身边有一条黄线。走的时候它变短，停在楼梯上不动也会慢慢变短，站上平台很快回满。
*为什么：* 没有敌人、没有计时，唯一的压力来自塔本身的高度。它逼人在平台停下来，而平台正是能看到对面那个人的地方。

**3. 失足。**
黄线归零时，人会滑回下面最近的一个平台，气息从那里重新攒。不会死，不会回到塔底。
*为什么：* 惩罚是损失一段路，不是损失一局。演示时评委第一次玩也不会卡死。

**4. 平台。**
每条楼梯有七个平台：塔底、五座断桥的桥头、塔顶。相邻两个平台之间一口气走得到，到达时气息大约还剩四分之一；中途停得太久就到不了。
*为什么：* 平台既是休息点，也是桥头。休息和合作发生在同一个位置，不用额外教。

**5. 断桥是可选的。**
塔里有五座断桥，每座从塔心两侧各伸出半截，中间留一道缝。两个人各站在同一座桥的两端（墙上有红月牙的平台），两半就伸长合拢。先后到位都可以。
*为什么：* 这是整个游戏里唯一需要两个人的动作。它不挡路，所以去做它是一个选择。

**6. 合拢的桥一直留着。**
桥一旦合拢就不会再断，两边的玩家都看得到，下一圈还在。
*为什么：* 塔里留下的每一座桥，都能说出是哪两个人、在哪一刻站在那里造成的。这是对主题 “Can you explain your choices?” 的回答。

**7. 天穹。**
走到塔顶的人穿过天穹，白光之后回到塔底，红色的头巾或围巾沾上白灰。只影响走到顶的那个人。
*为什么：* 登顶不是结束，是回到起点。白灰让别人一眼看出谁已经上去过。

**8. 两个镜头。**
近景跟着自己的人，贴着墙往上看。远景是剖开的整座塔，两个人只是两个小点。空格键硬切，各切各的，不影响对方。两个人站在同一座断桥两端时，镜头自动切到侧面，把两个人和整座桥放进一个画面。
*为什么：* 近景用来走，远景用来找对方和看已经造出来的桥。自动镜头只出现在两个人相遇的那一刻。

## 操作
- W / S 或 ↑ / ↓：上、下。手机上是 ▲ ▼ 按钮。
- 空格或 C：切换近景和远景。
- Tab：只有一个人时，切换控制另一个角色。
- Invite：复制给第二个玩家的链接。

## 没放进来的，以及原因
- **左右手分开的抓握、跳抓、伸手拉对方**：这些属于攀岩式的玩法。今天人物走的是楼梯，放进来会和动作对不上。
- **掉下去会死**：见第 3 条。
- **两个人不能说话、靠发光的抓点交流**：没做。现在两个人能互相看到的只有位置、黄线和白灰。

## 数值（都在 `src/world.js`）
| 含义 | 名字 | 现在的值 |
|---|---|---|
| 塔高 | `TOP` | 36 米 |
| 楼梯绕塔圈数 | `TURNS` | 1.75 圈 |
| 行走速度 | `SPEED` | 每秒 2.1 米 |
| 走动时气息消耗 | `DRAIN_MOVING` | 每秒 0.13（满值是 1） |
| 站着不动时消耗 | `DRAIN_HANGING` | 每秒 0.05 |
| 平台上恢复 | `REFILL` | 每秒 0.6 |
| 失足下滑速度 | `SLIDE` | 行走速度的 3.2 倍 |
| 断桥的高度 | `GAPS` | 全程的 18%、34%、50%、66%、82% |
| 算作站在桥头的范围 | `MARK` | 全程的 1.6%，约 1.1 米 |
